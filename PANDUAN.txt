E-PORTOFOLIO PPG PRAJABATAN SEMESTER II — MARUF HAMEN
Versi navigasi folder artefak & analisis (Oktober 2026)

MEMBUKA WEBSITE
1. Ekstrak seluruh berkas ZIP ke satu folder di laptop.
2. Buka index.html dengan browser (Chrome/Edge/Firefox).
3. Untuk publikasi online, unggah SEMUA berkas beserta folder assets/ dan dokumen/ ke penyedia hosting statis, misalnya GitHub Pages. Jangan hanya mengunggah index.html.

CARA MENGGUNAKAN MENU ARTEFAK DAN ANALISIS
- Klik menu ARTEFAK: muncul empat folder Siklus I, II, III, IV.
- Klik satu folder siklus: muncul daftar tujuh jenis bukti pembelajaran.
- Pilih salah satu jenis: tampil dokumen, media, video, atau bukti penilaian yang terkait.
- Klik tautan “Baca analisis artefak ini” untuk langsung menuju analisisnya.
- Klik menu ANALISIS: muncul empat folder Siklus I, II, III, IV.
- Klik folder siklus lalu pilih jenis analisis untuk membaca kajian akademik, refleksi, dan tindak lanjut.
- Ada tombol “Semua folder” untuk kembali serta tombol “Siklus I–IV” untuk berpindah siklus.
- Fitur pencarian dan filter lama telah dihapus. Halaman catatan kelengkapan administratif tidak lagi ditampilkan.
